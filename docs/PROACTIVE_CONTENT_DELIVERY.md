# 🤖 DeskClaw 智能主动推送功能

## 概述

智能主动推送让 DeskClaw 能够**预测你的信息需求**，并自动设置定时任务，在你需要之前就推送相关内容。即使你不主动发送请求，也能获得想要的信息。

---

## 🎯 功能特点

### 1. 行为模式学习

系统自动分析你的使用习惯：

```
观察行为 → 识别模式 → 预测需求 → 主动推送
```

**示例场景：**

- 📰 每天早上检查新闻 → 自动创建"每日新闻摘要"任务
- 📊 每周生成报告 → 自动创建"周报"任务
- 🔍 定期搜索某个主题 → 自动推送相关更新

### 2. 自动任务创建

基于学习到的模式，自动创建定时任务：

```typescript
// 自动生成的任务示例
{
  name: "Morning Tech News",
  cron: "0 9 * * *",  // 每天早上9点
  type: "prompt",
  config: {
    prompt: "获取最新的科技新闻并总结",
    autoSend: true
  }
}
```

### 3. 多渠道推送

内容通过多个渠道送达：

| 渠道        | 用途     | 示例               |
| ----------- | -------- | ------------------ |
| 🔔 系统通知 | 紧急提醒 | 错误警报、重要更新 |
| 💬 聊天消息 | 信息摘要 | 新闻摘要、报告生成 |
| 📊 仪表盘   | 数据更新 | 统计图表、状态更新 |

### 4. 智能反馈学习

系统从你的反馈中学习：

```
👍 点了"有用" → 增加类似推送频率
👎 点了"不有用" → 减少或停止此类推送
😶 忽略内容 → 降低推送优先级
```

## 🚀 使用场景

### 场景 1：每日新闻摘要

**你的行为：**

```
每天早上打开 DeskClaw 询问："今天有什么科技新闻？"
```

**DeskClaw 学习：**

```
1. 检测到每天早上都有新闻查询
2. 识别关键词：科技、新闻
3. 确定时间偏好：早上 9 点
4. 创建自动任务
```

**自动创建的任务：**

```typescript
{
  id: "auto-tech-news-daily",
  name: "每日科技新闻",
  description: "每天早上9点自动推送科技新闻摘要",
  cronExpression: "0 9 * * *",
  taskType: "prompt",
  taskConfig: {
    prompt: "请获取并总结今天的科技新闻，包括：1. 重要突破 2. 产品发布 3. 行业动态",
    modelId: "gpt-4",
    autoCreateMemories: true
  }
}
```

### 场景 2：定期报告生成

**你的行为：**

```
每周一运行"销售数据统计"工作流
```

**DeskClaw 学习：**

```
1. 检测到每周的重复任务
2. 识别工作流模式
3. 确定时间偏好：周一上午
4. 自动化执行
```

**自动创建的任务：**

```typescript
{
  name: "周报自动生成",
  cronExpression: "0 9 * * 1",
  taskType: "workflow",
  taskConfig: {
    workflowId: "sales-report-workflow",
    autoSend: true
  }
}
```

### 场景 3：监控提醒

**你的行为：**

```
经常检查系统错误日志
```

**DeskClaw 学习：**

```
1. 检测到监控模式
2. 识别关注点：错误、日志
3. 设置自动监控
```

**自动创建的任务：**

```typescript
{
  name: "系统健康监控",
  cronExpression: "0 */2 * * *",  // 每2小时
  taskType: "prompt",
  taskConfig: {
    prompt: "检查系统错误日志，如果有新错误，总结并报告"
  }
}
```

## 💡 推送类型

### 信息推送 (Information Push)

推送你可能感兴趣的信息：

```
📰 "你关注的AI领域有新进展：GPT-5即将发布..."
📊 "你的工作效率本周提升了23%，主要来自..."
🔔 "检测到3个新的系统更新可用"
```

### 任务执行 (Task Execution)

自动执行重复性任务：

```
✅ "已生成本周报告，包含：销售数据、用户增长..."
✅ "已备份你的工作文件到云存储"
✅ "已清理缓存，释放 1.2GB 空间"
```

### 智能提醒 (Smart Reminders）

基于上下文的提醒：

```
⏰ "根据你的习惯，现在该处理邮件了"
📌 "你有3个截止日期临近的项目"
💡 "上次你说想尝试那个新工具，现在要试试吗？"
```

## 🎛️ 用户控制

### 推送设置

```tsx
// 设置页面
<ProactiveContentPanel />
```

**功能：**

- ✅ 查看所有自动任务
- ⏸️ 暂停/启用特定任务
- 🗑️ 删除不需要的任务
- ⏰ 调整推送时间
- 📊 查看推送历史

### 反馈机制

每个推送都可以反馈：

```
┌─────────────────────────────────────┐
│  📰 每日科技新闻                    │
│                                      │
│  今天的主要科技新闻：...              │
│                                      │
│  [👍 有用] [👎 没用] [❌ 关闭]      │
└─────────────────────────────────────┘
```

### 隐私控制

```tsx
// 完全禁用主动推送
<Switch checked={proactiveContentEnabled} onCheckedChange={setProactiveContentEnabled} />
```

## 🔑 关键 API

### 获取自动任务列表

```typescript
const tasks = await window.electronAPI.evolution.getPredictedTasks();
// 返回: PredictedTask[]
```

### 获取推送历史

```typescript
const deliveries = await window.electronAPI.evolution.getDeliveries();
// 返回: DeliveredContent[]
```

### 切换任务状态

```typescript
await window.electronAPI.evolution.togglePredictedTask(taskId, enabled);
```

### 提供反馈

```typescript
await window.electronAPI.evolution.provideDeliveryFeedback(
  deliveryId,
  'positive' // or 'negative'
);
```

## 🎯 最佳实践

### 1. 渐进式启用

```
第1周：只观察，不推送
第2周：推送1-2个高置信度任务
第3周：根据反馈增加任务
第4周：完全启用
```

### 2. 用户确认

对于自动创建的任务，首次执行前请求确认：

```
"我发现你每天早上都查看科技新闻。
 要不要我每天早上9点自动推送摘要？"

  [是的，每天推送]  [先试一次]  [不需要]
```

### 3. 价值优先

只推送高价值内容：

```typescript
if (estimatedValue > 0.7) {
  enableAutoDelivery();
} else {
  awaitUserConfirmation();
}
```
